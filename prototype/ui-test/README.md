# GVT 云桌面控制台 UI Test

打开 `index.html` 即可体验静态原型。

本目录内容：

- `index.html`：主界面、设置登录、桌面详情、连接窗口。
- `styles.css`：桌面应用视觉样式。
- `app.js`：模拟桌面状态、模式切换、开关机、连接窗口、AUTO 窗口尺寸。
- `assets/desktop-win10.png`：桌面缩略图和连接窗口画面。
- `references/existing-autosize-client.png`：现有客户端窗口截图参考。

当前原型覆盖的产品点：

- 服务器地址和端口设置，保存后模拟登录并刷新。
- 桌面列表展示开机/关机、缩略图、端口、分辨率、模式。
- 每个桌面支持开机、关机、详情、连接。
- 模式 1 支持客户端解码，包含经典模式 30/60fps 和节能模式 15-60fps。
- 模式 2 支持物理 DP/HDMI 输出，键鼠和音频可切客户端或盒子外接，默认客户端。
- 点击缩略图弹出连接窗口，模式 1 显示画面，模式 2 显示同分辨率输入焦点窗口。
- 连接窗口包含 AUTO、断开、视频/输入/音频状态。
