# Golden Low-Latency 1920x1200 Client Baseline

Date: 2026-06-18

Keyword: `golden-lowlat-1920x1200-0941-no-green`

## Client

- Executable used in validation: `gvt_spice_viewer.video-debug.exe`
- Source captured in this branch: `src/gvt_spice_viewer.c`
- Video source size: `1920x1200`
- Video codec: H.264 RTP on UDP port `5004`
- SPICE audio/session: `192.168.0.188:5900`
- Native input: `192.168.0.188:5905`

## Required Runtime Arguments

```powershell
--video-codec h264 `
--video-port 5004 `
--latency 15 `
--no-drop-on-latency `
--spice-host 192.168.0.188 `
--spice-port 5900 `
--native-input `
--input-host 192.168.0.188 `
--input-port 5905 `
--source-width 1920 `
--source-height 1200 `
--auto-size
```

## Required Environment

```powershell
$env:GVT_SPICE_VIEWER_VIDEO_DEBUG='1'
$env:GVT_SPICE_VIEWER_DROP_COMPLETE_FRAMES='1'
$env:GVT_SPICE_VIEWER_UDP_BUFFER_SIZE='524288'
$env:GVT_SPICE_VIEWER_VIDEO_TAIL='queue name=post_decode_q leaky=downstream max-size-buffers=1 max-size-time=0 max-size-bytes=0 ! d3d11videosink name=vsink sync=false async=false qos=true max-lateness=0 processing-deadline=0 render-delay=0 enable-last-sample=false'
```

The validated client does not include the experimental local lock/unlock
GStreamer pipeline restart patch.

## Latency Check Tools

- Generic tool: `scripts/measure-gvt-video-latency.ps1`
- Start menu baseline wrapper: `scripts/run-golden-1920x1200-latency-check.ps1`
- Win+R baseline wrapper: `scripts/run-golden-1920x1200-winr-latency-check.ps1`

Validated results on 2026-06-18:

- Start menu (`ctrl,esc`) median: `573.2 ms`
- Win+R (`meta_l,r`) median: `622 ms`

These values include Windows UI animation and screenshot threshold detection
time. Use them only for same-environment A/B regression checks, not as pure
video pipeline latency.
